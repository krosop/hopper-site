Install

Four steps, about a minute.

The package is an unpacked extension. Edge will remember it until you remove it or move the folder.

  1. Download and unpack. Save the ZIP, then extract it to a folder you can find again. Keep the folder in place; Edge loads the extension from it.
  2. Open the extensions page. In Microsoft Edge, go to edge://extensions.
  3. Turn on Developer mode. Use the toggle in the left rail. The page will show the unpacked-extension controls.
  4. Load the folder. Choose Load unpacked and select the extracted folder. Pin Hopper to the toolbar to reach it quickly.
A note about updates

Unpacked extensions do not update themselves. When a new version is ready, download the new package, replace the folder, and reload Hopper from the extensions page. The Edge Add-ons listing, once live, will handle this for you.
