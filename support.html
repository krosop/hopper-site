Install

The extension doesn't appear.

Edge only loads unpacked extensions when Developer mode is on and the selected folder contains the manifest.

Load unpacked is missing

Open edge://extensions and turn on Developer mode in the left rail. The unpacked controls appear after that.

Edge says the manifest is missing

You selected the outer folder, not the extension folder. Select the folder that directly contains manifest.json, then try again.

The toolbar icon is hidden

Open the extensions menu in Edge, find Hopper, and choose the pin control. The popup is the whole interface; there is no separate window.

The extension disappeared after a restart

Check that the folder still exists and has not been moved or deleted. Unpacked extensions load from that folder each time Edge starts.

Conversion

The output isn't what you expected.

Conversion is local, so the fix is usually the source file, the chosen format, or the available memory.

A conversion stops or fails

Try a smaller file or a shorter trim first. Long videos and high quality settings need more memory. Close other heavy tabs and try again.

The audio is missing

Check the source file in another player. If the source has no audio track, no output format can add one. If it does, try MP4 or WebM as the output.

The result won't play in another app

Try MP4 for the widest compatibility. WebM is efficient but some editors and older players do not accept it. MP3 and M4A are audio-only.

The trim starts in the wrong place

Use seconds or mm:ss. Check the start is earlier than the end, and keep both inside the file's duration.

Companion

Auto-detect needs the helper.

Local file conversion does not need the companion. Auto-detect and web downloads do. If you use them, both halves have to be running and connected.

Is the companion available?

A Microsoft Store listing is coming soon. It is not offered on this page yet; auto-detect and web downloads wait for it, while local file conversion works without it.

The extension says the companion is offline

Start the companion, then reopen the Hopper popup. The extension only talks to the local service over 127.0.0.1; it does not use the internet.

A pasted link fails

Make sure it is a direct media link, not a page that needs a sign-in or a player. Some hosts block downloads or expire their links. Try the link in a browser first.
